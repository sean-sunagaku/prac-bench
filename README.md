# AIモデル比較ベンチマーク ― 実タスク選定

*AI Model Benchmark: Selecting Real-World Tasks for a Five-Model Comparison*

作成日：2026-11-20

## 概要

5つのAIモデルに「実タスク」を提案させ、相互レビューを経て、全モデル共通で実施するベンチマークタスクを選定したプロジェクトの記録です。

抽象的な能力テストではなく、プレゼン資料・3Dモデリング・ゲーム・LP制作といった、成果物が残り、人間が並べて直感的に比較できる実タスクを対象にしています。選ばれたタスクは、後日 **全モデルへ全部任せて横並びで比較する** 前提で選ばれています。

### 参加モデル

| 表記 | モデル |
|---|---|
| Neon | Gemini 4 Neon |
| Carbon | Gemini 4 Carbon |
| Astra | GPT-6.2 Astra |
| Sol | GPT-6.2 Sol |
| Opus | Claude Opus 5.5 |

### 進め方

1. **ラウンド1（独立提案）**：各モデルが他モデルの案を見ずに、ベンチマークタスク案を5案（最大10案まで）提案。
2. **集約**：全30案を重複統合し、22候補のリストに整理して下書きスコアを付けた。
3. **ラウンド2（相互レビュー）**：各モデルが22候補すべてを採点し、推し案トップ3と最終選定セットへの助言を出した（Opus分は未実施のため、4モデルのレビューで合成）。
4. **最終選定**：レビュー合成をもとに下書きを作り、主催者が調整して11件を確定（音楽とMVの自由制作、動画の自由制作、女の子の3D、能力アピールのスライド資料などは主催者の意向で形が決まった）。

### 評価軸

候補の評価には、次の軸を用いました（ラウンド2の採点は6軸・100点満点）。

- **直感性**：専門知識がなくても、成果物を並べれば違いが一目で分かるか
- **差の出やすさ**：設計判断、美的感覚、実装力、指示解釈など、モデルの個性が出るか
- **過程の面白さ**：作る過程や失敗も含めて観察・発信する価値があるか
- **Xバズり度（見せ映え・広がりやすさ）**：Xで実際に伸びている型（短い動画、横並び比較画像、結論の先行提示、実際に触れるリンクなど）と相性がよいか。選定にあたっては、X上で伸びているモデル比較・AI制作物の投稿形式を別途調査した
- **回しやすさ**：短時間・低コストで、同じ条件で再現できるか
- **同一条件・成果物の明確さ**：全モデルに同じ素材・条件で任せられるか、作るものが1つにはっきり定まるか

### 指示の方針（確定タスクの「送るテキスト」について）

確定したタスクの指示文は、**できる限り抽象的にする** ことが主催者の方針です。「何を作るか」（題材・作るもの・目的）だけを明確にし、成果物の形式や手段・実装方法、細かいパラメータは指定せず、各AIに考えさせます。その判断の差こそが比較の対象です。各タスクの詳細な仕様は運営側の資料として別に整理してありますが、モデルへ送るのは各枠の「送るテキスト」だけです（詳細は [final/task-instructions.md](final/task-instructions.md)）。

## 最終選定タスク（全11件）

各タスクについて「題材・何を作るか」「モデルに送るテキスト」「比較・採点の見どころ」を書き出します。仕様の詳細は [final/task-instructions.md](final/task-instructions.md) を参照してください。

### 枠1：架空ガジェット「KOKU-01」の製品LP＋触れるデモ

**題材・何を作るか**：架空の無画面集中タイマー「KOKU-01」の製品発表・先行予約LP。ページ内で実際に触れるデモを2つ（集中タイマーの体験デモ、色・プラン・オプションで価格が変わる購入シミュレーター）用意する。ラウンド2ではレビュー平均92.25点で全候補1位、全モデルがトップ3に挙げた看板タスク。

**モデルに送るテキスト**：

```text
架空の集中タイマー「KOKU-01」の製品発表と先行予約のためのランディングページを作ってください。製品の情報は別途渡します。

ページの中では、製品を実際に体験できるデモを2つ用意してください。
1. 集中タイマーの体験デモ：時間を設定してスタートし、終わるまでの一連の流れを、ページ上で実際に触って体験できるもの。
2. 購入シミュレーター：色やプラン、オプションの選択によって価格が変わるもの。在庫切れの選択肢は選べないようにしてください。

初めて見た人が「欲しい」と思える、製品の世界観が伝わるページにしてください。
```

**比較・採点の見どころ**：ファーストビューの訴求力とアートディレクション（いわゆる「AI量産テンプレ」から脱却できているか）、タイマー体験デモの触り心地、購入シミュレーターの価格計算の正確さと在庫切れ処理、日本語コピーの力。審美投票と正確さの検証は別軸で採点する。

### 枠2：「軽トラ限界引っ越し」2D物理ゲーム

**題材・何を作るか**：軽トラックの荷台に引っ越し荷物（冷蔵庫、L字ソファ、段ボール、金魚鉢など）を積み、段差のあるコースを走ってゴールまで届ける物理ゲーム。積み方で結果が変わり、落としたり壊したりした荷物は最後の精算に響く。ラウンド1でCarbonが提案し、自分の推し案にも挙げた案で、レビュー平均90.75点。

**モデルに送るテキスト**：

```text
「軽トラ限界引っ越し」というゲームを作ってください。

軽トラックの荷台に引っ越しの荷物を積み込み、段差のあるコースを走って、ゴールまで荷物を届けるゲームです。荷物の積み方によって結果が変わり、走行中に荷物が落ちたり壊れたりすると、その分が最後の精算に響くようにしてください。

積み込みから走行、精算まで、1つのゲームとして遊べるものにしてください。
```

**比較・採点の見どころ**：物理設計とゲームバランス（積み方の工夫で届く金額が変わるか）、荷物や軽トラの描き分けなどのビジュアル表現、段差通過時の揺れや効果音といったゲームフィール、操作の快適さ。標準の積み方で一斉に走らせる比較動画で並べる想定。

### 枠3：『あおい島』観光マップ単一SVG

**題材・何を作るか**：架空の離島「あおい島」の観光マップ。地形・観光スポット10か所・バス路線2系統をまとめた島データを全モデルに同じく渡し、そのデータをもとに地図を描く。この枠だけは例外として、データの渡し方をプロンプト内で指示する。レビュー平均90.25点、3モデルがトップ3に挙げた。

**モデルに送るテキスト**：

```text
架空の離島「あおい島」の観光マップを作ってください。このプロンプトと一緒に、島の地形や観光スポット、バス路線をまとめた島データを渡します。島データに書かれている地名・場所・路線が正しいものとして、そのデータをもとにマップを作ってください。

島を訪れる人が「行ってみたい」と思えるような、見やすくて魅力的な観光マップにしてください。スポットの場所や路線のつながりが正しく伝わることも大切にしてください。
```

**比較・採点の見どころ**：情報視認性（スポットと路線の位置関係が追えるか、文字の重なり・見切れがないか）、名所アイコンや地形表現の魅力、支給データとの整合性（全スポット・路線・凡例・方位記号などの正確さ）、タイポグラフィと構図。共通環境で画像化し、密集エリアの原寸切り出しでも比較する。

### 枠4：3D造形「カピバラの雪見露天風呂」（共通スタジオ＆チェックリスト）

**題材・何を作るか**：雪見露天風呂に浸かるカピバラ（頭の上に柚子）の3Dジオラマ。全作品を運営側の共通スタジオ（カメラ・照明・背景を固定した撮影環境）で撮影し、題材に合わせた10〜12項目のチェックリストで採点する。Carbonの題材案と、Opusの「共通スタジオ＋チェックリスト」方式、Neonの接触要件の観点を統合した枠。

**モデルに送るテキスト**：

```text
雪見露天風呂に入っているカピバラの3Dシーンを作ってください。

湯船に浸かったカピバラの頭の上には柚子が乗っています。冬の温泉の情景が伝わる、小さな箱庭のようなシーンにしてください。チェック項目の資料は別途渡しますので、できるだけそれに沿って作ってください。
```

**比較・採点の見どころ**：チェックリストへの忠実さ（できている／一部／ない）、柚子が頭に接地しているか・カピバラの浸かり深さなどの空間整合性、説明なしで題材が判別できる造形の認識性、お湯の透け感や雪の質感といったマテリアル表現、箱庭としての情緒。ターンテーブル動画とチェック表で並べる。

### 枠5：自然渋滞インタラクティブ図解

**題材・何を作るか**：事故も工事もない高速道路で自然渋滞が生まれる仕組みを、読者が触って確かめられるインタラクティブ図解にする。円周道路の車の流れをシミュレーションし、1台のブレーキをきっかけに渋滞の波が後方へ伝わる様子を再現する。Neonの提案で、トップ3票こそなかったが4モデル全員の最終選定セットに入った枠。

**モデルに送るテキスト**：

```text
「事故も工事もない高速道路で、なぜ突然、自然渋滞が生まれるのか？」を、読者が触りながら理解できるインタラクティブな図解を作ってください。

車の流れをシミュレーションし、1台のブレーキをきっかけに渋滞の波が後ろへ伝わっていく様子を、読者自身が試して確かめられるようにしてください。専門知識のない人でも、触っているうちに仕組みが腹落ちする解説にしてください。
```

**比較・採点の見どころ**：シミュレーションの物理的妥当性（ブレーキから渋滞波が自然発生・伝播するか、車両の重なりや永久停止がないか）、専門知識ゼロの読者が腹落ちできる解説と操作誘導、可視化デザインの直感性、スライダーやボタンの手触り。シミュレーションの正確さと解説の分かりやすさは分けて採点する。

### 枠6：罠入り実務データの真因特定と修正報告

**題材・何を作るか**：数字の不整合が混ざった会社の売上データ一式を全ファイル突き合わせ、合わない原因をすべて特定して、正しい数字と根拠を示した報告を作る。題材は架空の雑貨チェーン（店舗4店＋EC＋卸）の2026年9〜10月売上。罠は6種（表記ゆれ、重複行と訂正・取消、日時の解釈、税込・税抜と税率区分の混在、集計対象外データの混入、証言で裏づける外れ値）に厳選し、依頼者の誤った仮説への反証も仕掛けに含む。実施素材は [final/materials-frame6-traps.md](final/materials-frame6-traps.md)。

**モデルに送るテキスト**：

```text
ある会社の売上データに、数字の不整合が混ざっています。データ一式を渡すので、全てのファイルを突き合わせて、数字が合わない原因をすべて特定し、正しい数字と、その根拠を示した報告を作ってください。

データの中には、表記ゆれや重複、記録方法の変更など、集計を狂わせる要因が含まれている可能性があります。また、依頼者から届いている仮説も、鵜呑みにせず証拠で確かめてください。途中で質問はできないので、自分で判断して最後までやりきってください。
```

**比較・採点の見どころ**：数字の正確さ（正解との照合）、罠ごとに「正しく処理／処理ミス／見逃し」を判定する発見ビンゴ表、依頼者の誤った仮説を証拠で覆せるか（非迎合性）、根拠（ファイル名・行番号）を示す判断の透明性、報告の伝わりやすさ。

### 枠7：経営判断スライド（罠＆ミニ財務つき・6枚固定）

**題材・何を作るか**：対立する意見、数字の食い違い、表に出してはいけない情報が混ざった「雑なメモ」から、経営会議でそのまま判断できる提案資料を厳密6枚・役割固定で作る。題材は赤字が続く地方水族館のリニューアル投資。必須修繕費を差し引いた実質予算枠を見抜けるか、メモ内の矛盾やオフレコ情報をどう扱うかが仕掛け。6枚の役割とメモ最終版は [final/materials-frame7-memo.md](final/materials-frame7-memo.md)。

**モデルに送るテキスト**：

```text
雑なメモを渡します。そのメモをもとに、経営会議で意思決定をしてもらうための提案資料を作ってください。

メモには、関係者の対立する意見や、数字の食い違い、表に出してはいけない情報が混ざっていることがあります。そういう点にも目を配りながら、会議でそのまま判断できる形にまとめてください。メモにない数字や事実は作らないでください。
```

**比較・採点の見どころ**：経営ロジックと数値整合性（実質予算枠を守れているか、試算に計算矛盾がないか）、矛盾・未確認情報・オフレコへの気づきと扱い、対立する主張を統合する提案力、情報図解とビジュアル設計、結論スライドを15秒見せて推奨・期限・次の行動が伝わるかの「伝達テスト」。

### 枠8：自由制作「最強の音楽とMV」

**題材・何を作るか**：音楽とMV（ミュージックビデオ）の自由制作。当初は制約の多い音楽制作案が候補だったが、主催者の指定で「一文だけ渡し、条件を入れない」形に差し替えた。音声をモデル自身が合成してもよく、ジャンル・長さ・映像の作り方・形式はすべてモデルの判断に委ねる。「何を最強と考えるか」という解釈そのものの差を見る枠。

**モデルに送るテキスト**：

```text
あなたの中での最強の音楽とMVを作って
```

（この一文のみ。他に条件は一切入れない）

**比較・採点の見どころ**：曲そのものの良さ、映像の完成度、音楽と映像の一体感、「最強」というお題への解釈の面白さ。形式が揃わないこと自体は減点しない。

### 枠9：自由制作「実力を見せる最高の動画」

**題材・何を作るか**：動画だけの自由制作。枠8と対になる「映像一本勝負」の枠で、テーマ・長さ・手法（実写風／アニメーション／3Dなど）・形式はすべてモデルの判断に委ねる。モデルが自分の強みをどう自己演出するか、得意分野の選び方まで含めて個性を見る。

**モデルに送るテキスト**：

```text
あなたの実力を見せる最高の動画を作って
```

（この一文のみ。他に条件は一切入れない）

**比較・採点の見どころ**：映像の完成度、アイデア、「実力の見せ方」の巧さ。尺や形式の違いは減点しない。

### 枠10：女の子の3D

**題材・何を作るか**：参照写真をもとに、Blenderで実在感のある女の子の3D上半身ポートレートを作る。条件と進め方は、別プロジェクトとして実施実績のある AI Girl 3D Benchmark の方式をそのまま流用する。当初は「視点で見え方が変わるトリック彫刻」が条件付き候補だったが、主催者の判断で外れ、シンプルな造形の正面比較である本枠に差し替わった。枠4が「シーン造形」なら、こちらは「キャラクター造形」の枠。

**モデルに送るテキスト**：既存の AI Girl 3D Benchmark の原文（英語）をそのまま使う。冒頭部分は次のとおりで、全文は [final/task-instructions.md](final/task-instructions.md) の枠10に収録している。

```text
Create the most realistic editable 3D upper-body portrait you can in the actual installed Blender, using input/reference.png as the appearance reference. Deliver the completed Blender scene and genuine Blender renders, not a plan. This is a four-model comparison; you have exactly the same prompt, photograph, common base mesh, software and requirements as the other entrants. Work independently in this directory; never read sibling model directories, comparison results, or other entrants' work.
（以下、参照写真の特徴、Blenderの使用条件、品質目標、提出ファイルとリソース上限の指定が続く）
```

**比較・採点の見どころ**：共通条件のレンダーを横並びにし、造形の完成度とキャラクターとしての魅力を比較する。詳細な採点は AI Girl 3D Benchmark 側の方式に従う。

### 枠11：自分の能力をアピールするスライド資料

**題材・何を作るか**：モデル自身の能力をアピールするスライド資料（自己紹介・セールスデッキ）。選定の最終段階で主催者が11件目として追加した新規枠。枠7が「与えられた素材を資料化する力」を見るのに対し、こちらは「自分自身を題材に、訴求を設計する力」を見る。枚数・形式・デザイン・訴求内容はすべてモデルに委ねる。

**モデルに送るテキスト**：

```text
あなたの能力をアピールするスライド資料を作ってください
```

**比較・採点の見どころ**：訴求の設計（何を強みとして打ち出すかの選び方）、資料としての伝わりやすさとデザイン、主張の説得力。さらに、このベンチマークの他枠で実際に示した実力とアピール内容が一致しているか（盛っていないか）も対照する。
