README.md
# 軽トラ限界引っ越し

軽トラの荷台に引っ越しの荷物を積み、段差だらけの道を走って新居まで届ける 2D 物理ゲームです。
積み方しだいで、荷物は落ちたり、潰れたり、割れたりします。その分は最後の精算で弁償になります。

## 起動のしかた

`index.html` をブラウザ（Chrome / Safari / Edge / Firefox）で開くだけで遊べます。
ビルドやサーバーは不要です。ネットにつながっていない環境でも動きます（そのときはフォントだけ端末の標準フォントになります）。

## 流れ

1. **依頼を選ぶ**：3件の依頼票から選びます。お客様・区間・荷物の数と重さ・道の特徴・料金・「★お願い」が書いてあります。
2. **積む**：荷物置き場の荷札を荷台へドラッグ（クリックだけなら自動で置きます）。物理演算でそのまま積み上がります。荷物置き場は「積むおすすめ順」に並んでいます。
3. **走る**：段差・スピードバンプ・踏切・工事の鉄板・穴ぼこ・砂利道・木の橋・急坂を越えて新居へ。荷物がこぼれ落ちる瞬間はスローモーションになり、運転手がふきだしで反応します。
4. **精算**：感熱紙の明細書が1行ずつ印字され、最後に評価のハンコが押されます。

## 操作

| 場面 | 操作 |
|---|---|
| 積み込み | 荷札をドラッグして荷台へ（クリックだけなら自動で置く） / 置いた荷物もつかんで動かせる / 置いた荷物にマウスを乗せると「上に載っている重さ／耐えられる重さ」が出る |
| 回転 | ホイール・Q/E（15°ずつ）、右クリック・R（90°） / 画面右下の ↺ ↻ |
| ロープ | 「ロープ」を押して、黄色いフックから荷物へドラッグ（荷物→フックでも可）。ロープは荷物の上を通って反対側のフックにも掛かり、荷物を押さえます。結んだロープをクリックで外す。T でも切り替え |
| 走行 | → / D アクセル、← / A ブレーキ。止まってから ← を押し直すとバック。H クラクション、Esc 一時停止 |
| 共通 | M 音のオン・オフ |

スマホ・タブレットでは、荷札をドラッグ（またはタップ）して積み、走行は画面下のペダルで操作します。

## 精算のルール

- 基本料金（依頼ごと）＋ 早着ボーナス − 延着料
- **心付け**：依頼ごとの「★お願い」の荷物（ギター／結婚祝いの食器／仏壇と盆栽）を無事に届けると、お客様からもらえる
- **破損**：HP が減った割合ぶん弁償。HP がなくなると全損（全額）
- **落下**：走行中に荷物が地面に触れたら全額弁償
- **積み残し**：別便の手配料（3,000円 ＋ 弁償額の30%）
- **天地無用**を逆さま、**横倒し厳禁**を寝かせて運ぶと、残りの価値の半分を減額
- **過積載**：軽トラの最大積載量 350kg を超えると反則金 20,000円
- **ロードサービス**（横転・立ち往生からの復帰）：1回 10,000円

## 積み方のコツ

- 荷物置き場の上から順（重くて丈夫な物 → 布団 → ワレモノ → 転がる物）に積むと安定しやすい
- 重い物は下へ。上に重い物が載ったワレモノや段ボールは「潰れそう」マークが出ます
- ワレモノは布団に触れるように置くと衝撃がやわらぎます（「布団で保護」と表示）
- 鳥居（運転席の後ろの柵）より高く積んだ荷物と、「★お願い」の荷物はロープで押さえる
- 急発進・急ブレーキは荷崩れのもと。「大きな段差」の看板の前では這うように
- 3件目は全部積むと 355kg。何を積み残すかも作戦のうち

## ファイル構成

```
index.html        画面の骨組み
style.css         見た目（荷札・依頼票・感熱紙・ハンコ）
js/core.js        定数とユーティリティ
js/gfx.js         描画ヘルパーと配色
js/items.js       荷物26種（形・重さ・弁償額・強さ・絵）
js/truck.js       軽トラ（車体・サスペンション・4WD・フック・絵）
js/course.js      依頼3件（お願いと心付けを含む）とコース生成（段差・踏切など）
js/sim.js         物理シミュレーション（破損・落下・ロープ・自動配置・精算）
js/render.js      描画（背景・地形・看板・パーティクル・擬音・ふきだし・スロー演出）
js/audio.js       効果音・エンジン音・BGM（すべて WebAudio で合成）
js/game.js        画面遷移・入力・UI・スローモーション・運転手のひとこと
vendor/           Planck.js 1.5.1（2D 物理エンジン、MIT ライセンス）
tools/            ブラウザなしで物理とバランスを検証するスクリプト（Node.js）
```

検証スクリプトの例：

```bash
node tools/sim-test.js 1 9 clickrope pro   # 依頼1を「荷札を上から順にクリック＋ロープ」「段差手前で減速」で走らせる
node tools/balance.js                      # 3件 × 積み方 × 運転スタイルの結果一覧
tools/montecarlo-all.sh 6                  # 初期条件を少しずつずらして6回ずつ走らせ、ランクの分布を見る
```

積み方の指定：`click`（荷札を上から順にクリック）、`clickrope`（＋高い荷物にロープ）、`auto`（いちばん低い所へ順に落とす。背の高い山になる）、`rope`、`smart`。
運転の指定：`pro`（段差の手前で減速）、`cap`（一定速度）、`full`（アクセル全開）。
