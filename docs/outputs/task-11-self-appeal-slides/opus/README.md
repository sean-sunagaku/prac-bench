# Claude Opus 5.5 能力紹介スライド「一文で頼めて、最後まで任せられる。」

枠11「あなたの能力をアピールするスライド資料を作ってください」への opus の提出物です。

## 見るもの

| ファイル | 中身 |
|---|---|
| `slides.pdf` | **本体**（13ページ、16:9、フォント埋め込み） |
| `slides.html` | 元データ兼発表用。ブラウザで開き、← → キー（またはクリック）でページ移動。`#7` のように URL の末尾で7ページ目を開ける。`assets/` と同じ場所に置いて使う |
| `png/slide-01.png`〜`slide-13.png` | 1ページずつの画像（1920×1080） |
| `contact-sheet.png` | 全ページの一覧画像 |
| `speaker-notes.md` | 各ページの話す原稿 |
| `RUN.md` | 実行メモ（最初に決めたこと、作り方、検査の結果、出典、公平性、所要時間） |

## 資料の考え方

AIの自己PRは盛られがちです。そこでこの資料では、すべての主張に「どこで確かめられるか」のラベルを付けました。

- **実演**：この資料そのもので確かめられる
- **成果物**：このベンチマークの他の枠（opus の成果物と記録）で確かめられる
- **申告**：自己申告。ここでは確かめられない

主張は15件（実演4・成果物8・申告3）。13ページ目に、全主張と確かめる場所の一覧があります。

## フォルダの中身（作るための道具）

- `assets/fonts/`：資料で使う文字だけに絞ったフォント（Shippori Mincho、Zen Kaku Gothic New、IBM Plex Mono。OFL 1.1、ライセンス文同梱）
- `assets/portfolio/`：4ページ目のサムネイル（他の枠の opus の成果物から作成）
- `tools/build.mjs`：PNG・PDF・コンタクトシート・話す原稿の書き出し
- `tools/check.mjs`：見た目の自動検査（はみ出し・重なり・小さな文字・泣き別れ・コントラストなど）
- `tools/make-portfolio.sh`、`tools/pptx_reorder.py`、`tools/shot.mjs`：サムネイルづくり
- `checks/`：自動検査の記録（`check-log.jsonl` に全14回分、`latest.json` が最終結果＝0件）

再現手順は `RUN.md` の末尾にあります。
