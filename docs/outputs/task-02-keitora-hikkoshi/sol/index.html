    遊び方

    1. 荷物を積む

      荷物を選んで荷台のマスをタップ。ドラッグでも積めます。重い荷物は下段の中央に置き、割れ物は揺れに注意しましょう。

    2. 段差を越える

      → でアクセル、← でブレーキ。画面のボタンも長押しで操作できます。段差が近づいたら、表示された目安まで減速しましょう。

    3. 運賃を受け取る

      荷物の破損、落下、積み残しは減額になります。早く届けるほど時間ボーナスが増えます。
