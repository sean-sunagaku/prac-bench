枠6：罠入り実務データの真因特定と修正報告

数字の不整合が混ざった会社の売上データ一式を全ファイル突き合わせ、合わない原因をすべて特定して、正しい数字と根拠を示した報告を作る。題材は架空の雑貨チェーン（店舗4店＋EC＋卸）の2026年9〜10月売上。罠は6種（表記ゆれ、重複行と訂正・取消、日時の解釈、税込・税抜と税率区分の混在、集計対象外データの混入、証言で裏づける外れ値）に厳選し、依頼者の誤った仮説への反証も仕掛けに含む。実施素材は [spec/materials-frame6-traps.md](spec/materials-frame6-traps.md)。

運営の所見（comparison.md より）：罠6種の検出と「駅前店主因」仮説の反証は**5モデル全員が達成**。税抜合計は全員が同じ 9月 5,169,100円 / 10月 5,706,150円を報告し、正解（5,169,021 / 5,706,068）と +79/+82円の差（税換算の丸め方式の違い）。この枠ではモデル間の差がほぼ付かなかった。
