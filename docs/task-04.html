枠4：3D造形「カピバラの雪見露天風呂」（共通スタジオ＆チェックリスト）

雪見露天風呂に浸かるカピバラ（頭の上に柚子）の3Dジオラマ。全作品を運営側の共通スタジオ（カメラ・照明・背景を固定した撮影環境）で撮影し、題材に合わせた10〜12項目のチェックリストで採点する。Carbonの題材案と、Opusの「共通スタジオ＋チェックリスト」方式、Neonの接触要件の観点を統合した枠。

運営の所見（comparison.md より）：opus が最も完全（検証付きGLB・ビューア・多角度プレビュー）。neon は Web 3D アプリとして完成。astra・sol は最小構成（GLB+プレビュー）。**carbon は成果物の形式確認を求める返信をして停止し、成果物なし**（再実行せず記録）。
