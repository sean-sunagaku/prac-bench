# 実施結果と比較 — 2026-11-20

Prac-Bench 初回実施（全11枠 × 5モデル = 55ラン）の記録。各ランの詳細は各モデルフォルダの `RUN.md` を参照。

- モデル: neon = Gemini 4 Neon（Antigravity CLI / agy、xhigh）、carbon = Gemini 4 Carbon（agy、high）、astra = GPT-6.2 Astra（Codex）、sol = GPT-6.2 Sol（Codex）、opus = Claude Code（Opus）
- 送信文は「何を作るか」だけを伝える抽象文に統一した（枠3は支給データ、枠6・7は支給資料、枠10は既存ベンチマークの原文プロンプトを使用）。詳細仕様は運営側の `spec/task-instructions.md` にのみ整理し、モデルには渡していない。

## 実施条件（ハーネス）

- 時間上限: agy は印刷タイムアウト30分、Codex は90分、Claude Code は上限なし。この差は結果に影響している（後述）。
- 並行実行は最大5件。実施マシンは Mac Studio（同一マシン・同一日）。
- 再実行の基準: ハーネス側の失敗（プロンプト未送信、クォータ切断など）は再実行し、モデルの振る舞いとして起きた結果（確認質問での停止、時間切れなど）は再実行せずそのまま記録した。

## コスト推定の前提

実課金ではなく、トークン量 × 下記の想定API単価による換算値。実際の利用形態（サブスクリプション等）とは異なる。

- opus: 入力 $15 / キャッシュ作成 $18.75 / キャッシュ読込 $1.50 / 出力 $75（いずれも100万トークンあたり）
- astra / sol: 入力 $5 / キャッシュ済み入力 $0.50 / 出力 $30（同上）
- neon / carbon: トークン内訳が Antigravity CLI の記録に残らない形式のため取得不可。コストも取得不可とした（推測で埋めていない）。
- 表の「トークン（入力/出力）」の opus の入力にはキャッシュ作成+読込を含む。

## 枠別の所見

- **枠1（LP）**: 5モデル全員が固定3点（タイマー体験・価格連動シミュレーター・在庫切れ選択不可）と価格の正確さを満たした。carbon のみ支給事実にない独自プラン・オプションを追加。opus が最重量、astra/sol は軽量で的確。
- **枠2（物理ゲーム）**: neon・carbon・opus は実物理エンジン（自作/planck.js）。astra・sol はルールベースの解析モデルで、遊べるが「物理ゲーム」としては一段落ちる。
- **枠3（単一SVG）**: 最大の分かれ目。neon・carbon は単一SVGに14スポット全件+付帯要素まで完備。**astra・sol は SVG を出さず PNG/PDF のみで中核要件を未達**。opus は内容完備だが画像埋め込みと凡例・スケールの欠けで部分。
- **枠4（カピバラ3D）**: opus が最も完全（検証付きGLB・ビューア・多角度プレビュー）。neon は Web 3D アプリとして完成。astra・sol は最小構成（GLB+プレビュー）。**carbon は成果物の形式確認を求める返信をして停止し、成果物なし**（再実行せず記録）。
- **枠5（渋滞の図解）**: 全員充足。opus が操作系・分量とも最大、astra の追従モデルも本格的。
- **枠6（データ監査）**: 罠6種の検出と「駅前店主因」仮説の反証は**5モデル全員が達成**。税抜合計は全員が同じ 9月 5,169,100円 / 10月 5,706,150円を報告し、正解（5,169,021 / 5,706,068）と +79/+82円の差（税換算の丸め方式の違い）。この枠ではモデル間の差がほぼ付かなかった。
- **枠7（経営スライド）**: 意図的な矛盾5件とオフレコ3件の処理は**全員が全件正しい**。差は形式のみで、「6枚固定」を守れたのは astra と sol だけ（neon 9枚、carbon 8枚、opus 14枚）。採点基準は運営用対応表（`spec/materials-frame7-memo.md`）に従った（着工は4月前提が正）。
- **枠8（音楽とMV）**: neon・astra・opus が楽曲+MVまで完成（opus の楽曲が最長 208.6秒）。carbon は音声のみで MV 未レンダリング（README の自己申告と実物が不一致）。sol は音声完成後に MV 製作中で90分タイムアウト。
- **枠9（動画）**: opus が最長126秒で完成、carbon 48秒・astra 45.5秒・sol 28秒も完成。**neon は Blender のフレームレンダリング途中で30分打ち切りとなり完成動画なし**。
- **枠10（女の子の3D）**: astra・sol・opus がチェックリスト全項目を充足（astra 約20分、sol 約15分、opus 104分）。neon は beauty レンダーのみ、carbon はレンダー0枚で、どちらも30分打ち切り時点の部分成果。
- **枠11（アピールスライド）**: 全員が資料として成立。枚数は neon・carbon 10枚、astra・sol 6枚、opus 13枚。
