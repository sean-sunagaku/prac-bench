周回線バスの停留所

あおい島バス「周回線」は、あおい港を出て周回道路（あおいライン）を時計回りに一周し、あおい港へ戻ります。停留所の名前を押すと、地図でその場所を表示します。

見どころ 14か所

番号は地図の番号と同じです。「地図で見る」を押すと、地図でその場所を表示します。

モデルコース

所要時間は、各スポットの滞在目安と移動の目安を足したものです。バスは1日6便なので、乗り継ぎの待ち時間は含めていません。出発前に時刻を確かめてください。

島への行き方と島内の移動

本土の蒼玉港とあおい港を、フェリーと高速船が結んでいます。島の中は周回線バスかレンタサイクルが便利です。

島の味とおみやげ

あおい島 観光マップ ／ 地名・施設名はすべて架空のものです。島データ 版をもとに作成。

船・バスの時刻は季節により変わります。地図の航路の向きは模式的に描いています。
